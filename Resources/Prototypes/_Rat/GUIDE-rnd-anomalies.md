# Краткий гайд: НИОКР и космические аномалии

## Оборудование

| Прототип | Где ставить | Назначение |
|----------|-------------|------------|
| `RatResearchMinigameConsole` | Станция (наука) | Мини-игры для очков исследований |
| `RatSpaceAnomalyStudyConsole` | **Шаттл** | Консоль экспедиции по аномалиям |
| `RatSpaceAnomalyFieldScanner` | **Шаттл** (в руки/карман) | Сканирование в EVA |

Консоль изучения должна быть подключена к исследовательскому серверу (`ResearchClient`).

---

## Космические аномалии

### Как появляются

- Случайно в открытом космосе (вдали от гридов) — живут **12–25 мин**.
- Событием `RatSpaceAnomalyEvent` — **4 аномалии**, каждая живёт **30 минут**, затем исчезают с объявлением.
- О спавне — глобальное объявление с координатами.

### Типы (9 штук)

| Тип | Поведение в космосе |
|-----|---------------------|
| Гравитационная | Притягивает и отбрасывает объекты |
| Блюспейс | Телепортирует шаттл в случайную точку открытого космоса |
| Пирокластическая | Тепловая вспышка / малый взрыв |
| Электрическая | ЭМИ-импульс |
| Криогенная | Микрогравитационный сдвиг (подскальзывание) |
| Биоморфная | Рваные раны поблизости |
| Умбральная | Кратковременная слепота |
| Жидкостная | Едкий туман + подскальзывание |
| Ботаническая | Радиация и кислотный урон |

Спрайты — увеличенные ванильные аномалии (×4).

### Награда

**50 000–54 000** очков исследований за полностью изученную аномалию (один раз).

## Экспедиция (~12 этапов, рандом)

1. Откройте консоль на **шаттле**, выберите аномалию в радиусе 90 м, нажмите **«Начать экспедицию»**.
2. План экспедиции генерируется **случайно** и зависит от типа аномалии (первый этап — «фирменный» для типа).
3. Этапы чередуют **дистанционные головоломки** (с шаттла) и **EVA** (вне грида шаттла).

### Дистанционные этапы (консоль)

- Фазовая привязка (A + B = цель)
- Дешифровка шифра Цезаря
- Окно импульса (слайдер)
- Коммутация проводов
- Сетка памяти
- Гармонический синтез
- Архивация волны

### EVA-этапы

| Этап | Действие |
|------|----------|
| Полевое сканирование | Сканер на **6–22 м**, ~12 с |
| Ближний зонд | Сканер **≤ 8 м**, ~6 с |
| Спектральное сканирование | Сканер **≤ 8 м**, **18 с** |
| Инъекция реагента | Контейнер с нужным реагентом → Use на аномалии |
| Стабилизатор | Гаечный ключ на аномалии, удерживать **10 с** |

Провал любого этапа сбрасывает экспедицию.

### Важно

- Консоль — только **на гриде шаттла**.
- Сканер и инъекции — только **вне грида шаттла**.
- Нужно питание на консоли.

## Мини-игры на станции (`RatResearchMinigameConsole`)

Каждая игра — **2–3 подэтапа**. Слева выбор эксперимента, справа панель с подсказками.

| Игра | Подэтапы |
|------|----------|
| Frequency Tune | Полоса → калибровка → ключ модуляции (A×B+C mod 100) |
| Sequence Match | Прямая → обратная → сдвиг влево |
| Phase Lock | Сумма фаз → сумма + разница \|A−B\| |
| Harmonic Balance | Узкая стабильность → точное произведение |
| Waveform Pick | Отметить 2 шумовых канала → выбрать сигнатуру |
| Cipher Decrypt | Угадать сдвиг → расшифровать слово |
| Timing Pulse | Откалибровать центр → поймать импульс |
| Wire Routing | Порт красного провода → полная коммутация |
| Memory Grid | Запомнить → повторить в обратном порядке |
| Bit Repair | Посчитать биты → восстановить байт |

Очки идут на подключённый исследовательский сервер.
